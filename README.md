### 🐍 Contribution Controller

Turn your contribution graph into a retro snake game with the official GitHub Action:

[![Snake](https://img.shields.io/badge/Play%20Snake-Generate%20SVG-8B5CF6?style=for-the-badge&logo=githubactions&logoColor=white)](https://github.com/Platane/snk)

Official repo: [Platane/snk](https://github.com/Platane/snk)

```yaml
- uses: Platane/snk@v3
  with:
    github_user_name: PradhyumnaBait
    outputs: |
      dist/github-contribution-grid-snake.svg
```
